# Electric Garden: monochrome structural wireframes

These are monochrome structural comparisons for PR #71 (FD-30b redesign).
Colour, art and typography are stripped out so only hierarchy and layout remain.
Each file is 820x720 and shows BEFORE (left) and AFTER (right), with one caption line.
They show structure only; they are not visual design and not evidence of readiness.

- `moment-detail.svg`: stacked sheet to a composition (presence, eyebrow, statement, ledger, one primary)
- `today.svg`: the moment gains human context; the week becomes a dated ledger
- `person.svg`: four identical sections become four kinds
- `people.svg`: search-and-rows becomes two doors (find / ask) and a lettered index
- `tell.svg`: hairline rows and a bordered box become ruled ledgers; one primary action
