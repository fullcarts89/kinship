Where everything lives

The question this page answers: as Kinship grows from Tell · Memory · Today into Tell · Memory · Today · Ask (· Intentions), does the experience stay one product? The capability map below sorts every committed, next, Alpha and later item into four kinds of place. The three alternatives differ only on the one open question, where Ask lives; everything else is the same in all three.

Tell and Ask the distinction that decides the rest

Tell writes memory: a statement becomes items with sources, after understanding and (when needed) a question. Ask reads memory: a question is answered only from what was told, every line with its source, "nothing kept about that" when unsupported, and nothing is written. The contract forbids a chat as a primary surface and forbids guessing an ambiguous meaning; so a single field that silently decides whether you told or asked is the one design to avoid (alternative 3 shows it so it can be rejected on sight).

Alternative 1 · Two places and a door recommended

The bar stays Today · People. Ask lives inside People's field, which becomes Search or ask your people: a name filters the list as now; a question opens an answer sheet over the list, each line with its source, each line a door to the person. On a person's page, Ask about Priya → opens the same sheet scoped to her. The Tell dock stays Tell-only. The distinction is carried by place: you ask where you look for people; you tell where you capture.

Alternative 2 · Three destinations

The bar becomes Today · People · Ask. Ask is a page: a field and example questions, the answer as the same sheet. Clear and discoverable, but it changes the approved two-item bar, ships an empty destination before Alpha, and a question box as a destination invites general-chatbot expectations the contract rules out.

Alternative 3 · One field, two verbs

The Tell dock gains a Tell | Ask switch, so the same field does both everywhere. Fewest surfaces, but the dock's one job (capture) is muddied, the switch is one more thing in the most-used control, and a forgotten switch means a question written as a memory or a memory answered as a question: a trust failure the contract's "never guess ambiguous meaning" rule exists to prevent.

Recommendation: alternative 1, with Ask as a sheet reached from People's field and from a person's page, the bar unchanged, the dock Tell-only. It needs no new destination, no new navigation contract and no empty page before Alpha; it puts Ask next to the thing it searches; and it keeps a third destination in reserve if Ask proves heavily used (a reversible decision).
